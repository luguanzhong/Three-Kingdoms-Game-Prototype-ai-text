#  This project has ZERO third-party dependencies.
#
#  The game itself, the config loader, the save manager and the whole
#  test suite use ONLY the Python standard library:
#      os / sys / time / json / logging / argparse / importlib /
#      io / contextlib / tempfile / unittest / py_compile / re
#
#  Therefore:
#    - No installation step is required after `git clone`;
#    - `python -m pip install -r requirements.txt` is safe to run and
#      installs nothing;
#    - tests/test_architecture.py scans every import statement of the
#      production modules and fails if any non-stdlib module shows up,
#      so "zero dependencies" is enforced by an automated test rather
#      than by this comment.
#
#  NOTE: this file is intentionally kept pure ASCII. pip reads it with
#  the system locale encoding (GBK / cp936 on Chinese Windows), so any
#  UTF-8 non-ASCII comment here would break `pip install -r`.
#
#  Development environment: Python 3.13.1 on Windows 11.
#  No multi-version compatibility matrix has been tested, so no strict
#  minimum version is declared; the code uses no version-specific
#  syntax and no type annotations.
