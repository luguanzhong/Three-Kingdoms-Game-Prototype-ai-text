# 引擎核心（`src/`）

> 本目录是《三国·蜀汉突围》十一个区域之一。**分区规则、依赖方向与溯源机制见
> [docs/区域划分与溯源.md](../docs/区域划分与溯源.md)** —— 改本区域之前请先读那一份。

| 项目 | 内容 |
| :--- | :--- |
| **职责** | 确定性判定、主循环与状态、配置加载与校验、存档读写（**规则的唯一来源**） |
| **不做什么** | 不画界面、不读美术资产、不做展示排版；不引入任何第三方库 |
| **允许依赖** | 仅 Python 标准库 + 同目录模块（`config_loader` / `save_manager` / `游戏接口`） |
| **维护方 / 归属** | 规则与数值由本人设计；代码由 AI 协作实现 |
| **当前状态** | 玩法 v0.3.0 完整可玩；126 项自断言自测 + 108 个用例覆盖 |
| **如何推进 / 替换** | 改规则必须同步 `docs/规则说明.md` 与测试；改数值优先改 `config/` 而不是改这里 |
| **相关检查** | `tests/test_rules.py`、`test_boundaries.py`、`test_endings.py`、`test_architecture.py`、`test_legacy_suite.py` |
