# 蜀汉突围 · 规则说明

> 用途：一张速查表，把代码里已经实现的规则集中列出，便于对照代码与自测。
> 本文只写当前版本（v0.3.0）已有的规则，不含未实现构想。
> **数值来源（M2）**：下表所有数字都是 `config/` 配置文件的**默认值**——想要调参请改
> `config/units.json`、`schemes.json`、`seasons.json`、`diplomacy.json`、`battle.json`，
> 不必改代码；字段含义与校验规则见 README「配置说明」。

## 一、开局状态（公元208年·建安十三年九月·秋季）

| 势力 | 兵力 | 粮草 | 关键指标 |
| :--- | :--- | :--- | :--- |
| 蜀汉 | 18000（含永安3000） | 80 | 魏国压力 30、东吴好感 40、民心 100、精锐比例 0% |
| 曹魏 | 80000 | 200 | 扩张倾向 60 |
| 东吴 | 50000 | 120 | 观望态度 50 |

**曹魏城池**：襄阳（7000/曹仁）、宛城（8000/侯音）、樊城（6000/张郃）、上庸（4000/夏侯尚）、洛阳（12000/曹真，首都）。
**蜀汉固有城池**：成都、江陵、阆中、汉中、永安。

城破指令（决定将领生死）：提前撤退＝100% 存活但民心 -20；死守＝统御≥8 重伤撤离、统御<8 战死；默认驻守＝被俘（可花粮草 40 赎回）。

## 三、军事行动（确定性判定）

| 条件（进攻兵力 vs 守军） | 结果 |
| :--- | :--- |
| > 守军×1.5 | 强攻必胜，损失＝守军×0.8 |
| > 守军×0.8 | 可围攻，3 回合后破城（期间持续耗粮） |
| 0.5× ~ 0.8× | 无必胜把握，系统禁止进攻 |
| < 守军×0.5 | 必败，禁止送死；仅可选"死士突袭"（固定牺牲部队或将领） |

出征兵力＝**有效兵力**×60%；有效兵力＝兵力×(1+精锐比例/100)。守城方同样按有效兵力计算。
每次攻占城池：收编降卒＝守军×0.5、缴获城池粮草，随后触发连锁事件（东吴好感 -20 并要求割地：A 割地粮草-30、B 拒绝观望+25），且 3 回合后曹魏增兵（压力 +20、扩张倾向 +15）。
**洛阳**为北伐终极目标：需先取宛城或樊城打通粮道，攻占后立即触发"北伐大捷"结局（曹魏兵力 ×0.5、东吴观望归零、蜀汉兵力 +5000）。

## 四、计谋（前置条件达成即 100% 成功）

| 计谋 | 前置条件 | 效果 |
| :--- | :--- | :--- |
| 侦查粮道 | 粮草 ≥10 | 花 1 回合与粮草 10，获得粮道情报 |
| 劫粮道 | 拥有粮道情报 | 曹魏兵力 -30%、粮草 -20、扩张倾向 -10 |
| 侦查风向 | 粮草 ≥10 | 花 1 回合与粮草 10，获得风向情报 |
| 火攻 | 拥有风向情报 | 曹魏兵力 -25%、粮草 -30、扩张倾向 -15 |
| 据险而守 | 将领在汉中/阆中 且 任务为驻守险关 | 该将领防御加成翻倍 |
| 劝降 | 守将忠诚 <5 且 使臣智谋 ≥8 | 城池归蜀、守军加入（仅宛城侯音满足） |

## 五、每回合自动结算（13 步）

1. 曹魏兵力 ×1.02、粮草 +10；扩张倾向 >70 则压力 +5，<50 则压力 -2。
2. 粮草消耗＝兵力÷1000（驻守险关则减半）；粮草 <30 触发粮荒，兵力 ×0.95。**冬季**：消耗 ×1.5（军队在外）或 ×1.25（退守）、兵力冻伤 -2% 或 -1%。
3. 将领任务结算（屯田/练兵/外交使节/镇守子任务）。
4. 东吴骑墙：压力 >70 则观望 +3，<30 则观望 -2。
5. 田忌赛马：前线无统御≥8 名将（镇守/驻守/北伐任务）则压力 +8。
6. 围攻推进；7. 曹魏进攻（扩张倾向>70 且 压力>50，攻汉中）；8. 东吴背刺（亲魏且观望>85，攻江陵）；
9. 重伤恢复；10. 民心 +3；11. 连锁计时；12. 阈值事件；13. 东吴均势外交 AI。

## 六、阈值事件（条件触发即发生，同一条件持续期间只触发一次）

| 条件 | 事件 |
| :--- | :--- |
| 魏国压力 >80 | 魏军压境：兵力强制 -20% |
| 粮草 <20 且 东吴观望 >70 | 东吴闭粮：粮草 -10 |
| 兵力 <5000 | 国势衰微：所有将领忠诚 -2 |

## 七、日期与冬季

开局建安十三年九月；每回合结束月份 +1，月份 >12 则进位为次年一月。季节：9~11 秋、12~2 冬、3~5 春、6~8 夏。
首次进入十二月时弹出【冬至】提醒（仅一次，不影响数值）。

## 八、东吴均势外交 AI（每回合结算末尾执行一次）

势力值＝兵力 + 控制城池数×3000 + 将领总统御×200，势力比＝蜀汉势力值 ÷ 曹魏势力值。

| 势力比 | 倾向 | 每回合变化 | 附加事件 |
| :--- | :--- | :--- | :--- |
| >1.2 | 亲魏 | 观望 +3、好感 -2 | 观望 >80 密使通魏（一次）；>90 触发魏吴盟约（压力 +20，玩家盟约作废） |
| <0.8 | 亲蜀 | 观望 -2、好感 +3 | 好感 >70 提出结盟：接受（压力 +10、观望 -40）或婉拒（好感 -10） |
| 0.8 ~ 1.2 | 观望 | 观望 -1、好感 +1 | 主动接触标记复位，允许下次触发 |

## 九、结局

北伐大捷（洛阳归蜀）＞ 星落秋风（兵力归零或压力 >100）＞ 汉家尚有可为（20 回合且兵力 >18000）＞ 中性结局（20 回合但兵力未超过初始值）。
