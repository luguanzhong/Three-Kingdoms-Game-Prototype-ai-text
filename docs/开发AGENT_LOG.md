## 2026-10-09 深夜（续）—— 官方底图铺进游戏

### 修改文件
- `ui/底图.py`（新增）：底图图层；`ui/地图.py`：`_铺底图/设显示底图/载入底图/对齐底图档位/底图状态`
- `ui/主界面.py`：工具栏「官方底图」开关 + 自检 5 条
- `config/投影.json`：中央经线 105 → **109.85721**（配准拟合得出）
- `tests/test_basemap.py`（新增 11 条）、`run_tests.py`、`CHANGELOG.md`

### 关键判断
- **旋转必须消掉**：tkinter 的 PhotoImage 不能旋转。圆锥投影的轴向只由中央经线决定，
  于是把配准里的 2.82° 旋转折算成中央经线偏移（109.857°E），六参数退化成纯缩放＋平移。
- **缩放必须吸附**：底图只能按 m/n 缩放。打开底图时把画布缩放吸附到 m/n 档位，
  保证底图与矢量用同一比例尺；关闭时不吸附（硬要求：与以前完全一致）。
- **只裁可见区**：整幅图放大后是上亿像素，必须按可见范围裁剪再缩放。

### 踩到并修掉的坑
- 工具的中央经线一度"反馈漂移"：扫描起点跟着 config 走，上一轮写回的值变成下一轮起点，
  越跑越偏（20 像素误差、λ₀ 漂到 114.6°E）。**把扫描参考经线钉死在 105°** 后消失。
- 顺手"修正"初值（改用最大陆地块外接框、参照框只用境内点）反而把扫描踢出了正确吸引域 ——
  已回退，并在注释里如实写明"这个初值是实测能落进正确吸引域的写法"，不再假装它更有道理。
- `config/投影.json` 里我用 ASCII 双引号写中文说明，直接让 JSON 解析失败；
  好在 `载入投影参数()` 的兜底逻辑把原因记了下来（这条兜底设计因此得到了实战验证）。
- 自检里 `delete("all")` 之后 `_底图项` 成了失效 id，关掉底图时必须一并清空。

### 测试结果
- 全量 **186 项通过**（113.8 秒）；`ui/主界面.py --自检` 退出码 0（含底图 5 条）。

### 未做 / 待办
- **我无法看到 tkinter 窗口的真实画面**（截不了用户桌面）。底图的几何对齐是用可计算的方式

## 2026-10-09 深夜 —— 换圆锥投影 + 官方底图自动配准

### 需求来源

- `tools/生成州域对照图.py`、`tools/地图精度预览.py`：不再各抄一份投影公式，统一调用 `ui/地图.py`

- `run_tests.py`（两个新测试模块登记进「地理 / 美术」）、`README.md`、`CHANGELOG.md`

### 关键技术判断（都写进了代码注释与文档）
- **官方图上是"着色 = 中国领土"**：海洋与邻国都是白的。所以拿海岸线去配是配不上的 ——
  正确做法是拿**中国的形状**（Natural Earth 50m 国界，公有领域）去配"着色区"。这一条定了整个工具的方向。
- 参照数据特意**不用** `config/map.json` 里那 89 点中国轮廓：那是本项目自己概括画的，
  拿它拟合官方图等于"自己对着自己"，会把我自己画的误差固化进配准结果。
- 圆锥常数最终**以 `config/投影.json` 为准**，工具负责扫描核对（发现偏得多会明确报警），
  这样游戏投影与写出的六参数严格同一个 n，底图与州郡界不会有额外偏差。

### 踩到并修掉的坑
- "图像像素 → 世界坐标"的**南北符号写反**：整幅图上下颠倒，中国直接跑到图外。
  往返自检（2.8e-14 度）与视觉核验两个手段一起才定位到它。
- 我手算的圆锥常数 0.5911395 是**错的**（正确值 0.5914674959）——是 `tests/test_projection.py`
  里独立重算的那条用例把它抓出来的。这也说明"测试自己重算一遍"比"抄一个数"可靠。
- 坐标下降一开始会滑到更差的局部解（把图放得更大、把国界外的点全判错）：
  改成"从扫描得到的最好解继续精修"后稳定在 2.38 像素。
- 我的 `写PNG` 产出的 PNG 用 .NET 打开正常，但视觉接口报"图片格式错误"；
  转成 JPEG 后视觉核验通过。工具仍写 PNG（它本身是合法的），这条只影响核验流程。

### 测试结果
- 全量 **175 项全部通过**（90.3 秒）：原 159 项 + 投影 9 项 + 底图配准 7 项。

### 未做 / 待办
- **底图还没有画进游戏**：`config/底图配准.json` 已经能用了，但 `ui/地图.py` 还没读它、
  也还没有"底图开关"。这是下一步。
- 底图东北角（漠河、抚远一带）比真实国界少 50–90 千米；南海诸岛插图与右侧图例色块会被

### 关键决定与理由
- 六参数仿射用于**描图**；四参数（横纵独立缩放 + 平移）用于**游戏内画底图**：
  tkinter Canvas 只有整数倍 `zoom`/`subsample`，不能平滑缩放位图，退化成四参数后可一步换算。
- 配准系数落成仓库根目录 `配准.json`，游戏读文件而非把数字抄进代码 → 换底图零代码改动。

### 测试结果
- 全量测试见本轮末尾运行结论；美术区域 16 项、配准数学 10 项单独复跑均通过。
