# 叙事文案（`src/（暂）`）

> 本目录是《三国·蜀汉突围》十一个区域之一。**分区规则、依赖方向与溯源机制见
> [docs/区域划分与溯源.md](区域划分与溯源.md)** —— 改本区域之前请先读那一份。

| 项目 | 内容 |
| :--- | :--- |
| **职责** | 事件文本、将领台词、结局评语等一切「给人读的长文字」 |
| **不做什么** | 不参与数值计算；不与判定逻辑混写 |
| **允许依赖** | — |
| **维护方 / 归属** | 本人 |
| **当前状态** | ⏸ **暂不抽离**（当前约 183 处中文文案内联在 `src/` 中）；按计划在正式写剧情时抽出为数据文件 |
| **如何推进 / 替换** | 写剧情时抽出到 `config/文案.json`（或 `config/events.json`），届时本区域升为独立目录 |
| **相关检查** | 抽出后补用例（键齐备、占位符可解析） |
