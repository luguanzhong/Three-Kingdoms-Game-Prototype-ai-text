# 构建发布（`tools/`）

> 本目录是《三国·蜀汉突围》十一个区域之一。**分区规则、依赖方向与溯源机制见
> [docs/区域划分与溯源.md](../docs/区域划分与溯源.md)** —— 改本区域之前请先读那一份。

| 项目 | 内容 |
| :--- | :--- |
| **职责** | 打包单文件 exe、生成州域对照图、按区域查看历史、资产台账校验与生成、字体子集化 |
| **不做什么** | 不参与游戏运行；产物（`dist/`、`build/`）不入库 |
| **允许依赖** | 全部区域（只读） |
| **维护方 / 归属** | AI 协作实现 |
| **当前状态** | `打包exe.py`（产物 11 MB）、`生成州域对照图.py`、`区域日志.py`、`资产台账.py` |
| **如何推进 / 替换** | 新增工具保持「仅标准库」；需要第三方（PyInstaller、fonttools）时**仅作构建期依赖**并在脚本内说明 |
| **相关检查** | 工具脚本可 `py_compile`；`资产台账.py 校验` 纳入提交前检查 |
