# 测试（`tests/`）

> 本目录是《三国·蜀汉突围》十一个区域之一。**分区规则、依赖方向与溯源机制见
> [docs/区域划分与溯源.md](../docs/区域划分与溯源.md)** —— 改本区域之前请先读那一份。

| 项目 | 内容 |
| :--- | :--- |
| **职责** | 分类回归用例、零随机架构检查、界面与地图检查、旧自测的全量包装 |
| **不做什么** | 不在测试里复制生产逻辑；不修改生产代码（测试只读） |
| **允许依赖** | 可读全部区域；不被任何区域依赖 |
| **维护方 / 归属** | 代码由 AI 协作实现；验收标准由本人制定（如「断言只增不减」） |
| **当前状态** | 108 个用例全绿；含 126 项旧自断言自测的全量回归 |
| **如何推进 / 替换** | 新增功能必须同时加用例；修好的缺陷要固化成回归用例 |
| **相关检查** | `python run_tests.py`（全量）／`--fast`／`--区域 美术`（只跑某区域） |
