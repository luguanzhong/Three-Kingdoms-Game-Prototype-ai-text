# 美术资产（`assets/`）

> 本目录是《三国·蜀汉突围》十一个区域之一。**分区规则、依赖方向与溯源机制见
> [docs/区域划分与溯源.md](../docs/区域划分与溯源.md)** —— 改本区域之前请先读那一份。

| 项目 | 内容 |
| :--- | :--- |
| **职责** | 字体、配色、图片、音效等一切非代码资产，以及它们的**来源与许可台账** |
| **不做什么** | 不放代码；不放游戏数值（那是 `config/`） |
| **允许依赖** | 无（纯资产 + 声明文件） |
| **维护方 / 归属** | **本人手工**（书法、绘画）；过渡期可含第三方开源资产（须在台账登记来源与许可） |
| **当前状态** | 本轮新建。`theme.json`（配色与字体声明）与 `manifest.json`（资产台账）已就位；字体待入库，图片与音效目录为空 |
| **如何推进 / 替换** | 见 `assets/README.md` 的替换流程：放文件 → 加台账 → 改 `theme.json` → 校验 → 提交 |
| **相关检查** | `python tools/资产台账.py 校验`；`tests/test_assets.py` |
