# 界面外壳（`ui/`）

> 本目录是《三国·蜀汉突围》十一个区域之一。**分区规则、依赖方向与溯源机制见
> [docs/区域划分与溯源.md](../docs/区域划分与溯源.md)** —— 改本区域之前请先读那一份。

| 项目 | 内容 |
| :--- | :--- |
| **职责** | 窗口与布局、战区地图渲染、交互对话框；把引擎状态画出来、把玩家意图送回去 |
| **不做什么** | **不含任何游戏规则**（判定一律调 `src/`）；不写死颜色与字体（读 `assets/theme.json`） |
| **允许依赖** | `src/`（单向）、`assets/`、`config/`；仅标准库（tkinter） |
| **维护方 / 归属** | 代码由 AI 协作实现；视觉方向与界面取舍由本人定 |
| **当前状态** | 可玩完整流程（地图可缩放、城池可点、三个存档位） |
| **如何推进 / 替换** | 换皮只改 `assets/`；新增引擎菜单**不需要改界面**（菜单会被自动解析成按钮） |
| **相关检查** | `tests/test_gui_facade.py`（与引擎逐字段一致）、`tests/test_map.py`、`tests/test_assets.py` |
