# 历史归档（`legacy/`）

> 本目录是《三国·蜀汉突围》十一个区域之一。**分区规则、依赖方向与溯源机制见
> [docs/区域划分与溯源.md](../docs/区域划分与溯源.md)** —— 改本区域之前请先读那一份。

| 项目 | 内容 |
| :--- | :--- |
| **职责** | 历史版本快照、被替换下来的资产（只增不改） |
| **不做什么** | 不参与运行、不被任何代码导入 |
| **允许依赖** | 无 |
| **维护方 / 归属** | 归档性质 |
| **当前状态** | 3 个历史版本快照（v0.2.0 / v1.1 / 修改前） |
| **如何推进 / 替换** | 替换下来的旧资产移入此处留档，并在台账中把状态改为「已归档」 |
| **相关检查** | `tests/test_architecture.py` 会确认归档目录确实存在（白名单前提） |
