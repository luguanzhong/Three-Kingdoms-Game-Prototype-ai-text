# 数值配置（`config/`）

> 本目录是《三国·蜀汉突围》十一个区域之一。**分区规则、依赖方向与溯源机制见
> [docs/区域划分与溯源.md](../docs/区域划分与溯源.md)** —— 改本区域之前请先读那一份。

| 项目 | 内容 |
| :--- | :--- |
| **职责** | 五类游戏数值（兵种/计谋/季节/外交/战斗）与地图数据（十三州边界、十城池经纬度与归属） |
| **不做什么** | 不放代码、不放美术资产；不存放运行时产物（存档在 `saves/`） |
| **允许依赖** | 无（纯数据，被 `src/` 与 `ui/` 读取） |
| **维护方 / 归属** | 数值平衡与历史考据由本人确定 |
| **当前状态** | 5 份数值配置 + `map.json`；加载带校验（非法配置给出明确报错并整体回退） |
| **如何推进 / 替换** | 改数值只改这里，不必动代码；`map.json` 与 `docs/三国州域对照图.html` **共用同一份数据** |
| **相关检查** | `tests/test_boundaries.py`（配置校验）、`tests/test_map.py`（地图数据合法性） |
